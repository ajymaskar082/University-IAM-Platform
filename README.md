# University IAM Platform
## Университеттің жеке басты сәйкестендіру және рұқсаттарды басқару платформасы

### Жоба туралы

University IAM Platform – университет студенттеріне, оқытушыларына және әкімшілеріне арналған жеке басты сәйкестендіру және қолжетімділікті басқару веб-жүйесі.

Жүйе пайдаланушыларды қауіпсіз сәйкестендіруге, олардың рөлдерін басқаруға және ақпараттық ресурстарға қол жеткізу құқықтарын бақылауға арналған.

### Жобаның мақсаты

Университеттің ақпараттық жүйелеріне бірыңғай және қауіпсіз кіру мүмкіндігін қамтамасыз ететін платформа әзірлеу.

### Қолданылатын технологиялар

- Java 17+
- Spring Boot
- Spring Security
- Thymeleaf
- PostgreSQL
- JWT (jjwt)
- BCrypt
- TOTP
- Maven
- JUnit 5

### Жүйенің негізгі мүмкіндіктері

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Құпиясөздерді BCrypt алгоритмі арқылы хештеу.
3. TOTP арқылы екі факторлы аутентификация (MFA).
4. JWT Access және Refresh токендерін қолдану.
5. Рөлдерге негізделген қолжетімділікті басқару (RBAC).
6. Атрибуттарға негізделген қолжетімділікті басқару (ABAC).
7. Жүйеге кіру әрекеттерін шектеу.
8. Әкімші панелі арқылы пайдаланушыларды басқару.
9. Пайдаланушылардың әрекеттерін тіркеу және бақылау (Audit Log).

### Пайдаланушы рөлдері

- ADMIN – жүйе әкімшісі.
- TEACHER – оқытушы.
- STUDENT – студент.

### Жүйенің негізгі модульдері

- Аутентификация модулі.
- Рөлдер мен құқықтарды басқару модулі.
- Веб-интерфейс.
- Аудит және есеп беру модулі.
- Тестілеу модулі.

### Жобаның құрылымы

Жоба Spring Boot архитектурасы негізінде әзірленеді. Әрбір модуль жеке міндет атқарады және өзара байланыста жұмыс істейді.

### Тестілеу

Жүйенің функционалдық мүмкіндіктерін тексеру үшін JUnit 5 көмегімен кемінде 20 автоматтандырылған тест әзірленеді.

### Жобаны іске қосу

```bash
mvn clean install
mvn spring-boot:run
```

### Жоба туралы

Бұл жоба университеттің оқу тапсырмасы аясында топтық жұмыс ретінде әзірленеді. Жобаны жоспарлау Trello платформасында, ал бағдарламалық кодты әзірлеу GitHub платформасында жүргізіледі.
